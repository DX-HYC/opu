# CONTRIBUTING

欢迎为 {{name}} 贡献代码！

## 开发流程

1. Fork 本仓库
2. 创建特性分支 `git checkout -b feature/awesome-thing`
3. 提交改动 `git commit -m 'feat: add awesome thing'`
4. 推送到分支 `git push origin feature/awesome-thing`
5. 发起 Pull Request

## 提交规范

推荐遵循 Conventional Commits 规范：

- `feat:` 新功能
- `fix:` 修复
- `docs:` 文档
- `refactor:` 重构
- `chore:` 杂项

## 行为准则

请保持友好、专业的沟通环境。
